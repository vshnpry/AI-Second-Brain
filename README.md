\# 🧠 AI Second Brain



\### Your Personal Knowledge \& Learning Agent



AI Second Brain is an intelligent personal knowledge system that allows users to upload documents, ask questions, explore relationships between concepts, and discover connections between new and existing knowledge.



\---



\## 🚀 Features



\- 📚 PDF document upload

\- 🧠 Document-based AI memory

\- 🔎 Semantic search using embeddings

\- ⚡ FAISS vector memory

\- 🤖 Groq LLM integration

\- 🔗 Automatic knowledge graph generation

\- 🔍 Topic Explorer

\- ✨ Connection Discovery

\- 💬 Conversational memory

\- 📄 Source-aware answers

\- 💾 Persistent memory

\- 🎨 Gradio web interface
